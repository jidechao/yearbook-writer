# 交付前自检清单

交付年鉴稿件前逐项核对。任何一项不通过，先修正再交付。

## 事实与来源

- [ ] 所有事实、数据、人名、单位名均可在素材中找到出处，无虚构
- [ ] 时限外（非记述年度）的内容已剔除
- [ ] "下一步打算""存在问题""经验体会"等总结性内容未入正文
- [ ] 多份素材口径矛盾处已向用户确认，未擅自取舍
- [ ] 无涉密及敏感内容（军事、信访、工资奖金、宗教等）

## 文体与人称

- [ ] 全篇第三人称，无"我X""本X""我馆/我局/我单位"
- [ ] 记述体：无议论、无抒情、无评价语（"成效显著""反响热烈""扎实推进"等）
- [ ] 无总结式/口号式条目标题（"强化XX""提升XX""抓好XX"）
- [ ] 无"着力""认真""充分""深入""扎实""进一步"等修饰词
- [ ] 无"计划""预计""下一步"等展望词

## 结构与格式

- [ ] 【概况】置于篇首，涵盖单位性质、职能、年度总体情况
- [ ] 条目标题用【】标注，不超过 13 字（或符合随附规范）
- [ ] 排序：概况 → 无具体时间的综合条目 → 专题条目按月日排序
- [ ] 条目一段成文（综述除外）
- [ ] 每条末尾有（撰稿人）署名，每条不超过两人；署名优先取自素材文末署名，素材无署名时才标（XXX）并告知用户
- [ ] 全角标点：无半角引号/括号混入正文（素材中的半角标点已规范化）

## 时间、数字、名称

- [ ] 无"今年""去年""目前""最近"等含混时间词；同比写"比XXXX年"而非"比上年"
- [ ] 年月日用阿拉伯数字；无具体时间的条目以"XXXX年，"开头
- [ ] 单位首次出现用全称并括注简称，之后统一用简称
- [ ] 人名直书，职务在姓名前，同一条目内职务不重复出现
- [ ] 小数保留两位；超万位用"万"为单位；计量单位用中文全称且同条内一致
- [ ] 同一数据前后文一致

## 字数

- [ ] 概况 ≤ 1000 字，综合性条目 ≤ 800 字，专题性条目 ≤ 500 字（或符合随附规范）
